# ranveer.me

Source code for my personal website and blog: [ranveer.me](https://ranveer.me)

Built with:

- SvelteKit
- MDsveX
- Tailwind CSS
- TypeScript

The site is statically generated and deployed through GitHub Pages, with the custom domain managed through AWS Route 53.

I use the site to write about economics, finance, technology, personal projects and other things I find interesting.
